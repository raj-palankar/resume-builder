# 📄 Resume Builder

> 🧑‍💻 A simple and modern web-based Resume Builder built with Python, Flask, HTML, CSS, JavaScript, and SQL.

## ✨ Features

- 📝 Create and manage resume details
- 🎨 Simple and responsive UI
- ⚡ JavaScript-powered interactions
- 🐍 Flask-based backend
- 🗄️ SQL database support
- 📂 Clean project structure

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| 🐍 Python | Backend |
| 🌐 Flask | Web Framework |
| 🧱 HTML5 | Structure |
| 🎨 CSS3 | Styling |
| ⚡ JavaScript | Interactions |
| 🗄️ SQL | Database |
